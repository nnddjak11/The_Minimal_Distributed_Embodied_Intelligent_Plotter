# 轻量化分布式具身智能绘图仪（已部署——演示版）
## 核心硬件与功能
- **主控制板（SOC）**：RK3566（4GB 内存 + 32GB 存储），基于 x96x6 电视盒子，搭载 Station-M2 版本 Armbian 系统，部署语音识别 TFLite 模型、轮廓提取 TFLite 模型。
- **第一块微控制器（MCU）**：ESP32 N16R8，负责 UDP 消息传输，通过 INMP441 麦克风模块实现录音功能。
- **第二块微控制器（MCU）**：PICO W（RP2040 + ESP8285），通过 ULN2003 驱动板控制 2 个 28BYJ48 步进电机，实现绘图笔的运动控制。

### 硬件选型说明
放弃使用 PICO W 内置的 ESP8285 无线模块，原因是：
- 单次接收数据量无法超过 30 字节；
- 需编写大量代码控制其 AT 指令集，开发成本过高。

## 技术栈信息
- **开发语言**：C 语言、Python 3.10
- **框架/运行时版本**：TensorFlow & TFLite Runtime v2.14.0（终端部署时 numpy 版本需低于 2.x）
- **部署环境**：基于 Podman 容器的 Armbian 系统，底层为 Ubuntu ARM 22.04
